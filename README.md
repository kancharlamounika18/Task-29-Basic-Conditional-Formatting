Objective

Use Excel conditional formatting to automatically highlight important top, bottom, negative, and high-volume values in a retail-sales dataset.

Tool Used

•
Microsoft Excel

This project uses the Sample Superstore retail-sales dataset with 10,800 records.

https://github.com/leonism/sample-superstore

•

Workbook Sheets

Formatted_Sales

Contains the Sample Superstore sales records with automatic formatting rules applied to the Sales, Profit, Discount, and Quantity columns.

Rules_List

Documents the purpose and visual result of each conditional-formatting rule.

Read_Me

Contains the project objective, dataset information, and instructions for testing the rules.

Conditional Formatting Rules

The workbook includes the following automatic rules:

1.
Top 10 Sales Values — Highlights the ten highest transaction sales.

2.
Bottom 10 Profit Values — Highlights the ten lowest transaction profits.

3.
Negative Profit Values — Flags loss-making transactions where profit is below zero.

4.
Discount Color Scale — Shows low-to-high discount levels using a three-color scale.

5.
Quantity Data Bars — Compares quantities using proportional blue data bars.

6.
Top 10% Sales Values — Highlights the highest-sales 10% of transactions.

How to Use

1.
Download and open basic_conditional_formatting.xlsx in Microsoft Excel.

2.
Open the Formatted_Sales sheet.

3.
Review the automatically highlighted sales, profit, discount, and quantity values.

4.
Edit a value in one of the formatted columns to observe the rule update automatically.

5.
Open the Rules_List sheet to review the rule definitions.
